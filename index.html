Progressive Web App (PWA) Mobile Setup

How to install this app to your smartphone or desktop home screen.

Standalone Mode Enabled
A iPhone / iPad (Safari)
  1. Open this app in Safari.
  2. Tap the Share button (box with upward arrow at the bottom).
  3. Scroll down and tap Add to Home Screen.
  4. Tap Add in the top-right corner. It will appear with its own icon on your home screen.
B Android / Chrome / Desktop
  1. Click the Install App button at the top of the screen.
  2. Alternatively, tap the browser menu (⋮ or install icon in URL bar).
  3. Select Install App or Add to Home screen.
  4. The app launches in full-screen standalone window with complete offline storage.

Reset or Seed Data

Restore the initial 14-day sample records or wipe local storage.

PWA

Install to Home Screen

Installing adds an app icon to your phone or desktop, removes the browser address bar, and works completely offline.

Installation Steps:

iOS / Safari: Tap Share [↑] then tap Add to Home Screen [+].

Android / Chrome: Tap Menu [⋮] then select Install app.

Desktop (Chrome/Edge): Click the install icon [⊕] on the right side of the address bar.

Remove custom question?

Past logs containing this symptom will remain in your history, but it won't appear on future daily forms.

Clear all tracking history?

This will delete all saved daily logs from this browser. This action cannot be undone unless you have a JSON backup file.
